# Bottleneck Framework

A universal scoring framework applied to every industry-chain node.

## Dimensions (rate each: Low / Medium / High / Extreme)

- **Demand Growth** — how fast is demand for this node growing?
- **Supply Elasticity** — how quickly can supply expand? (Low elasticity =
  supply is hard to add)
- **Expansion Time** — how long does adding capacity take? (record as a
  duration, e.g. "3-5 years")
- **Substitutability** — how easily can buyers replace it? (Easy / Medium / Hard)
- **Pricing Power** — can suppliers of this node raise prices?
- **Market Attention** — how much attention does the market already pay?
- **Profit Capture** — how much of the chain's profit lands here?

Plus an **Opportunity Score** of 1–5.

## Qualification rule (strict)

Mark a node **Structural Bottleneck** ONLY when all three hold:

```text
Demand Growth  = High or Extreme
Supply Elasticity = Low
Substitutability = Hard
```

If only demand growth is strong, mark it **Growth Area**. Everything else is
**Neutral**. Never inflate a growth area into a bottleneck.
